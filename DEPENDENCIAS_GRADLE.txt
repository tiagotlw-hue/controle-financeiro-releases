============================================================
SEU PROJETO USA "VERSION CATALOG" (gradle/libs.versions.toml)
Siga ESTAS instruções em vez das do arquivo antigo.
============================================================

PASSO A — Abra o arquivo: gradle/libs.versions.toml
(fica na raiz do projeto, não dentro de "app")

Ele tem 3 seções: [versions], [libraries], [plugins].
Adicione as linhas abaixo em cada seção correspondente.

--------------------------------------------
[versions]
--------------------------------------------
Adicione (mantendo as que já existem):

firebaseBom = "33.1.2"
playServicesAuth = "21.2.0"
coroutinesPlayServices = "1.8.1"
googleServices = "4.4.2"

--------------------------------------------
[libraries]
--------------------------------------------
Adicione:

firebase-bom = { group = "com.google.firebase", name = "firebase-bom", version.ref = "firebaseBom" }
firebase-auth-ktx = { group = "com.google.firebase", name = "firebase-auth-ktx" }
firebase-firestore-ktx = { group = "com.google.firebase", name = "firebase-firestore-ktx" }
play-services-auth = { group = "com.google.android.gms", name = "play-services-auth", version.ref = "playServicesAuth" }
kotlinx-coroutines-play-services = { group = "org.jetbrains.kotlinx", name = "kotlinx-coroutines-play-services", version.ref = "coroutinesPlayServices" }

--------------------------------------------
[plugins]
--------------------------------------------
Adicione:

google-services = { id = "com.google.gms.google-services", version.ref = "googleServices" }

============================================================
PASSO B — build.gradle.kts DA RAIZ do projeto (o de fora, não o de "app")
============================================================

No bloco "plugins { ... }" que já existe, adicione a linha do google-services,
ficando parecido com isto:

plugins {
    alias(libs.plugins.android.application) apply false
    alias(libs.plugins.kotlin.compose) apply false
    alias(libs.plugins.google.services) apply false   // <-- ADICIONE ESTA LINHA
}

============================================================
PASSO C — app/build.gradle.kts (dentro da pasta "app")
============================================================

1) No bloco "plugins { ... }" adicione (SEM "apply false" aqui):

plugins {
    alias(libs.plugins.android.application)
    alias(libs.plugins.kotlin.compose)
    alias(libs.plugins.google.services)   // <-- ADICIONE ESTA LINHA
}

2) No bloco "dependencies { ... }" adicione:

dependencies {
    implementation(platform(libs.firebase.bom))
    implementation(libs.firebase.auth.ktx)
    implementation(libs.firebase.firestore.ktx)
    implementation(libs.play.services.auth)
    implementation(libs.kotlinx.coroutines.play.services)

    // Confira se já existem (o Android Studio costuma criar por padrão);
    // se não existirem, adicione também:
    implementation(libs.androidx.activity.compose)
    implementation(libs.androidx.lifecycle.viewmodel.compose)
    implementation(libs.androidx.material3)
}

============================================================
PASSO D — Sincronizar
============================================================
Clique em "Sync Now" (aparece uma barra amarela no topo do arquivo).
Se der erro de versão, me manda o print da mensagem que eu ajusto.

============================================================
IMPORTANTE — google-services.json
============================================================
Não esqueça de colocar o arquivo "google-services.json" (baixado do
console do Firebase) dentro da pasta "app/" do projeto — é ele que faz
o plugin google-services funcionar. Sem esse arquivo, o Sync vai falhar
com erro "File google-services.json is missing".
